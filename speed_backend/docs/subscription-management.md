# 订阅管理第一版

## 入口和模块

- 独立一级菜单 **订阅管理 → 订阅列表**，路由 `/subscription/list`，不属于 Xray 管理。
- 独立后端模块 `speednet-module-subscription`，通过现有 Xray 服务配置节点、入站和路由。
- 会员用户使用现有 `member_user`，与客户登录系统共用；必须选择存在且启用的用户。
- 后端启动自动执行 V14、V15、V16 迁移。订阅以系统生成的编号识别，不填写名称；旧名称列仅保留升级兼容，旧迁移不修改。
- 超级管理员重新登录可获取新菜单；普通角色须授予 `subscription:*` 对应权限，使用租户套餐的安装还须把菜单加入套餐。

## 创建与使用

1. 在地区与城市管理维护地区城市，添加 SOCKS5 出口节点并上架。
2. 配置服务器面板地址与 API Token，在服务器上创建已启用的 VMess / VLESS / Trojan 入站；初始 `clients: []` 可以为空。
3. 新建订阅，选用户、期限、流量、重置规则、节点数量上限和可选地区城市范围。
4. 每个出口节点分配一组服务器、入站和用户连接域名/IP。连接地址是用户访问入站的地址，不是出口节点地址；允许用自定义域名覆盖服务器 IP。
5. 保存后持久化随机 UUID（VMess/VLESS）或随机密码（Trojan）。订阅生效时后台检测 SOCKS5、部署出站、创建专属用户出口路由，再创建/启用客户端并回读核对。未来开始的订阅不会提前部署。
6. 详情页查看配置结果、流量、关联订单、分配记录和操作历史。失败可重试同步。
7. 使用“查看订阅链接”复制链接给关联用户。链接返回 Base64 编码的连接列表和 `subscription-userinfo` 流量/到期响应头，仅返回已生效、配置成功的订阅。

节点上架只改变领用资格。已分配节点下架不会自动撤销已有订阅；新分配只能使用上架节点。变更节点连接信息会使其配置版本变化，订阅同步会重新检测并更新已有出站。

## 授权和操作规则

- 用户必选，来源订单号可空。目前订单模块没有启用，订单关联是可选外部订单号；创建、续费、加流量分别记录关联，支付自动开通尚未接入。
- 每份订阅可配置 1–20 个不同出口节点，每个分配产生独立客户端。多个节点的流量合并计入同一订阅。
- 待生效、生效、暂停、耗尽、到期、结束是业务状态。待同步、同步中、已核对、失败是独立配置状态。
- 结束不可恢复；需要再次授权时新建订阅。暂停不会顺延到期时间。到期、暂停、结束、额度耗尽会禁用客户端并移除该客户端的出口路由。
- 撤销保留共享入站、其他用户客户端和共享出口配置，避免影响其他订阅。无引用的出站可在节点详情中核对后手动清理。
- 延长：未到期从原到期时间增加天数，已到期从当前时间增加；指定日期必须晚于原到期时间和当前时间。不会改变 UUID。
- 增加流量：增加周期额度，保留已用量；无限流量不支持加额度。
- 重置流量：先采集服务器最新计数，保存周期结束记录，再将周期已用量清零。累计历史保留，手动重置不改变原自动重置日程。采集失败拒绝重置。
- 自动重置可选不重置、每月、固定天数；仅在未结束、已开始且未到期时执行。重置会记录旧周期流量。
- 重置订阅链接立即失效旧 Token，UUID 保持。重置客户端认证先禁用、核对并删除旧认证，再保存新随机认证、重新配置；用户需刷新订阅重新连接。
- 客户端凭据和订阅链接单独权限控制。常规列表和详情不返回 Token/密码/UUID，数据库存储使用既有加密处理器。敏感接口不记录凭据响应和订阅链接访问日志。
- 节点详情从真实订阅分配记录显示关联用户、到期时间、订阅状态和授权状态。有效用户数表示有效授权关系，不是实时在线人数。

## 流量和任务实现

- 自动扫描使用现有 Quartz 任务管理，入口 **基础设施 → 定时任务 → 订阅扫描**，处理器 `subscriptionScanJob`，参数留空，默认 Cron `0 * * * * ?`（每分钟一次）。可在后台修改执行周期、暂停/恢复、立即执行、查看任务日志。原 `@Scheduled` 触发和 `speednet.subscription.reconcile-delay-ms` 配置已移除。
- V16 创建默认任务记录；启动时只注册尚不存在的 Quartz 任务，使用数据库里保存的 Cron 和暂停状态。已有 JDBC Quartz 任务不会重置，后台删除任务后启动也不会自动重建。Quartz 被禁用时不会启用替代扫描器，启动日志会明确提示。
- 每轮扫描最多 100 份订阅，已生效、待生效、暂停/耗尽及未成功同步的记录会继续核对。任务日志记录扫描、接受（包含已在队列）、队列满延期和提交失败数量。扫描成功表示提交完成，不表示远端配置已完成，具体结果在订阅详情中查看。
- 新建、延长、结束订阅和手动同步继续立即入队，无需等待下一轮 Cron。暂停 Quartz 任务只停止周期扫描，不取消已有队列任务，也不禁止业务操作立即入队。
- 服务器客户端累计计数按增量入账，重复采集不重复累计；计数下降按远端重置处理。服务器清零前未采到的尾部流量无法还原，应避免在其他面板手动清零。
- 采集失败时停止发布订阅连接并尝试禁用客户端，恢复采集后自动核对恢复。服务器不可达时禁用可能失败，失败状态明确保留并重试。
- 上传+下载或仅下载计费，无限流量显式区分零额度。有限双向计费写入面板客户端额度保护；跨客户端总额度按周期汇总撤销，因此存在采集间隔内的超额窗口，不能作为实时精确计费器。仅下载计费由后台汇总处理。
- 客户端到期时间同时写入面板，面板自身可执行到期禁用。订阅链接按当前时间判断授权，不等待定时任务才拒绝过期链接。
- 任务使用有界队列；数据库保存期望状态和失败结果。服务重启后定时核对会继续处理，而不是重新生成凭据。各订阅使用数据库行锁串行处理；节点和订阅共享本进程服务器配置锁。
- 第一版按单后端实例运行。多实例部署需要服务器分布式锁，避免整份 Xray 路由配置竞争覆盖。

## 支持范围与后续

- 第一版支持 VMess、VLESS、Trojan，TCP / WebSocket / gRPC，普通或 TLS。Reality、其他协议/传输和 TCP HTTP 伪装暂不生成订阅，创建时明确报错。
- 面板适配使用现有 `/panel/api/inbounds` 客户端接口和 `/panel/api/xray` 配置接口，参考 [3x-ui 官方 API 文档](https://github.com/MHSanaei/3x-ui/wiki/Configuration)。API 版本不兼容会报告配置失败。
- 回读核对不代表用户端到端连接成功。SOCKS5 检测来自管理后端；真实服务器出站连通性仍需联调。
- 后续可增加套餐、支付自动开通、自动故障迁移、用户门户订阅页面、提醒和设备/速率限制。第一版用户可以直接通过订阅链接导入客户端。

## 验证

- 订阅策略、连接序列化、配置与撤销、增量流量、到期/耗尽、会员禁用、失败处理、凭据复用及显式重置的单元测试。
- H2 MySQL 模式执行 V14、V15、V16（测试中只将 MySQL bit 字面量转换成数字），验证独立菜单、加密字段、无订单创建以及租户锁/读/写隔离。
- Quartz 注册、启动保留 Cron/暂停状态、删除任务不复活、跨租户扫描、错误日志和真实内存 Quartz 的暂停/恢复/立即执行验证；后端完整打包。
- 前端 TypeScript / ESLint / Vite 构建检查（本次调度改造未改动前端）。
- 尚未向真实 3x-ui 服务器创建测试订阅；上线前应使用测试用户和测试入站验证完整连接与流量统计。

首次同步顺序：对已生效订阅先创建尚未完成首次配置的客户端（禁用状态），再读取客户端流量，随后准备 SOCKS5 出站及用户路由，最后启用客户端并回读核对。创建失败或流量读取失败时不启用；再次同步使用原 UUID，避免重复创建。待生效订阅在开始时间前不创建远端客户端。已完成配置的客户端继续先采集流量再决定是否启用，以正确执行流量上限和到期限制。

面板客户端 API 兼容：先调用旧版 inbounds 客户端接口，仅 HTTP 404 时改用新版 clients/add、clients/update/{email}、clients/traffic/{email}。新版更新保留原 UUID、订阅标识和其他客户端字段；发现客户端同时关联多个入站时停止覆盖。释放使用 detach 移除当前入站关联，不全局删除客户端。HTTP 状态码会显示在订阅错误信息中。
