# SpeedNet 客户前台

Vue 3 + TypeScript + Element Plus 前台。包含邮箱验证码注册、邮箱密码登录、订阅套餐与订单，以及参考仓库内 v2board 主题布局的客户仪表盘和工单系统。

## 运行

先启动 `speed_custom_backend`（默认端口 `48081`），再运行：

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:5173`。Vite 将 `/custom-api` 转发到后端。构建命令：`pnpm build`。

注册、登录成功后进入仪表盘。套餐、订单、订阅与流量区域已接入真实业务接口。工单支持提交、对话、截图、状态处理及未读提醒；主后台需执行 V10 迁移，配置方法见 [客户工单说明](../speed_backend/docs/support-tickets.md)。

客户首页集中展示真实订阅状态、流量额度、待办订单、最近订单和最新工单，支持复制订阅链接和业务快捷入口。各数据模块独立处理加载失败，页面可见时自动刷新；手机端采用两列指标与单列内容布局。

### 官网首页

根路径 `/` 为无需登录的服务介绍首页，包含服务优势、订阅方式、使用流程、常见问题以及注册 / 登录入口；客户中心仍位于 `/dashboard`。套餐价格以登录后的实际数据为准，官网不显示示例价格。首页适配桌面和手机，登录、注册页面可返回官网。
